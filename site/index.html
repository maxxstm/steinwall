SteinWall runs next to Claude Code and Codex on your machine. It stops runaway costs, blocks dangerous actions before they happen, gets stuck agents unstuck and checks new skills and MCP servers before you install them.

Users have saved ≈ $0 so far

Install in one command

What it does

Cost brake

Daily and monthly budget. A warning at 80 %, a hard stop at the limit. Lift it for today with one command.

Action guard

Asks or blocks before recursive deletes, force pushes, reading .env files or SSH keys, and piping downloads into a shell.

Loop rescue

When the same error comes back three times, the agent is told to change course. Repeating the same command blindly gets blocked.

Extension scanner

Checks skills, plugins and MCP servers for prompt injection, hidden shell commands and data exfiltration before you install them.

Limit handoff

Before the 5-hour or weekly limit runs out, the agent writes a handoff file. The next session continues from there.

Daily report

What it cost, what it saved, what it blocked. Every amount is an estimate at API list prices and is marked ≈.

Install

Claude Code:

claude plugin marketplace add maxxstm/steinwall
claude plugin install steinwall@steinwall

Codex (then approve the hooks once with /hooks):

codex plugin marketplace add maxxstm/steinwall
codex plugin add steinwall@steinwall

Needs Node.js 20 or newer. Everything runs locally: no prompts, code or keys leave your machine.
