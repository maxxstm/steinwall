Claude Code Kosten begrenzen

Claude Code rechnet pro Token ab, über API-Schlüssel oder im Rahmen eines Abos. Teuer wird es selten durch einzelne Fragen. Teuer werden lange Sitzungen, große Kontexte und Agenten, die in Schleifen laufen.

1. Kosten sichtbar machen

Was du nicht siehst, kannst du nicht begrenzen. Claude Code zeigt mit /cost die Kosten der aktuellen Sitzung. Eine Statuszeile, die laufend die Tageskosten anzeigt, ist hilfreicher: Du merkst früh, wenn eine Sitzung aus dem Ruder läuft.

2. Den Kontext klein halten

Jede Anfrage schickt den bisherigen Gesprächsverlauf mit. Bei 150.000 Tokens Kontext kostet schon das Mitschicken spürbar Geld, auch wenn ein Teil davon aus dem Cache kommt. Drei Gewohnheiten helfen:

  • /compact mit einem Fokus verwenden, sobald eine Aufgabe abgeschlossen ist, z. B. /compact Fokus: Login-Fehler.
  • Für neue, unabhängige Aufgaben eine neue Sitzung starten statt die alte weiterzuführen.
  • Gezielt lesen lassen: konkrete Dateien und Ordner nennen statt „schau dir das ganze Projekt an“.

3. Modelle bewusst wählen

Das stärkste Modell ist für Planung und schwierige Änderungen da. Suchen, Lesen und Zusammenfassen erledigt ein günstigeres Modell genauso gut, zum Beispiel in einem Subagenten. Mit /model wechselst du das Modell der Sitzung.

4. Schleifen früh stoppen

Ein Agent, der denselben fehlschlagenden Befehl zehnmal wiederholt, zahlt jedes Mal für den ganzen Kontext. Sag ihm nach drei gleichen Fehlern, dass er die Ursache benennen und den Ansatz wechseln soll.

5. Ein hartes Budget setzen

Ein Tages- und ein Monatsbudget mit Warnung vor dem Limit und einem harten Stopp am Limit verhindern den bösen Überraschungsmoment. SteinWall macht das lokal als Plugin für Claude Code und Codex:

claude plugin marketplace add maxxstm/steinwall
claude plugin install steinwall@steinwall
/steinwall:budget --daily 20 --monthly 200

Bei 80 % kommt eine Warnung. Am Limit werden weitere Aktionen gestoppt, bis du das Budget anhebst oder den Stopp für heute aufhebst. Dazu zeigt SteinWall eine Statuszeile mit den Tageskosten, stoppt Schleifen und blockiert riskante Befehle.

Alle Beträge sind Schätzungen zu API-Listenpreisen. Bei Abos entsprechen sie dem API-Gegenwert, nicht deiner Rechnung.
